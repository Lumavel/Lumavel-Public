# Lumavel (private monorepo)

**As of:** 2026-09-07  
**Slug:** `lumavel`  
**Status:** private production monorepo

## What it is

The **Lumavel** repository is the private code home for Lumavel LLC: one public website (`lumavel.co`), product apps, shared packages, database migrations, Factory Floor, and docs. Marketplace is a **tool**. Mission is people.

Do not call this repository “Nexus.”

## Public door

- Site: https://lumavel.co  
- Public README-only GitHub: https://github.com/Lumavel/Lumavel-Public  
- This repo (private): https://github.com/Lumavel/Lumavel

## Where in this repo

- Website: `apps/lumavel-website` (Vercel root)  
- Inventory: `docs/REPO_MAP.md`  
- Iter curriculum: `docs/product/iter-discendi/`

## What it is not

- Not the public GitHub showcase (that is Lumavel-Public).  
- Not a holding company or a portfolio of sister brands.  
- Not a second Vercel app per product — public products fold into lumavel.co.
