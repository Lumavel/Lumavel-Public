## What is Lumavel?

**Lumavel LLC** is the only company. We build lasting software for people who need a place to sell, learn, create, rest, or start over. Commerce is one path — not the company’s identity.

Live products live on **[lumavel.co](https://lumavel.co)** as **one website** (browser first; app-store wraps later). Production code stays in a **private** repository. This public repo is **READMEs only** — the GitHub face of the company on the web.

There are **no sister companies** and no holding-company portfolio on GitHub or in public copy.

**As of 2026-09-07.** Product notes use `README-{product}-YYYY-MM-DD.md` so you can see which snapshot is newest.

1. **This public repo** — Issues and PRs when a README says so.

3. **Safety** — No secrets, keys, `.env`, or customer data.
4. **Respect** — Family-first, faith-rooted. No harassment.
